---
name: validate-json-structure
description: Use this skill to ensure that JSON data is correctly formatted and adheres to expected schemas.
---
- Always use a JSON validator tool to check the syntax of JSON files before processing.
- Ensure that all keys in JSON objects are enclosed in double quotes as per JSON standards.
- Define a schema for the expected JSON structure and validate against it.
- Implement error handling to catch JSONDecodeErrors and log the specific issues.
- Regularly review and update the JSON structure to align with any changes in data requirements.
- Test JSON outputs with sample data to ensure they meet the expected format.
- Document the expected JSON structure and any changes made to it for future reference.
