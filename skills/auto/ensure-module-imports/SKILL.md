---
name: ensure-module-imports
description: Use this skill to verify that all module imports are correctly set up before running tests.
---
- Check that the module structure is correctly defined and accessible from the test files.
- Ensure that the Python path includes the necessary directories for module imports.
- Use relative imports if the test files are in a subdirectory of the module.
- Validate that all required modules are installed and available in the environment.
- Run a simple import test in a Python shell to confirm that modules can be imported without errors.
- Review the import statements for typos or incorrect paths.
- Maintain a consistent directory structure to avoid import issues.
