---
name: prevent-test-modification
description: Use this skill to ensure that test files remain unmodified during development.
---
- Always create new test files for additional tests instead of modifying existing ones.
- Review the test files before committing changes to ensure no original tests are altered.
- Use version control tools to track changes in test files and revert if necessary.
- Establish a naming convention for new test files to differentiate them from existing ones.
- Communicate with team members about the importance of preserving original test files.
- Regularly run automated tests to verify that existing tests remain intact.
- Document any changes made to test files in a changelog for transparency.
